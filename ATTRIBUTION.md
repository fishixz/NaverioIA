# Referências e atribuição

Este protótipo segue o conceito de um mundo 3D estilizado, inspirado na arquitetura e direção visual de [thaslle/world](https://github.com/thaslle/world), projeto open-source sob licença MIT. O cenário e personagem desta primeira versão foram desenhados com geometria procedural própria em React Three Fiber; nenhum modelo GLB, textura, personagem ou trecho de código do projeto de referência foi importado até aqui.

A experiência **Navério** não reutiliza a narrativa, os sons ou o personagem da obra de referência. Se futuramente forem incorporados ativos de terceiros, verificar as licenças específicas e preservar os créditos.
