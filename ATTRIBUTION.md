# Referências e atribuição

O projeto foi estruturado com React Three Fiber, Three.js e Drei. A arquitetura de experiências 3D do projeto open-source [thaslle/world](https://github.com/thaslle/world), publicado sob licença MIT, foi consultada como referência técnica e de organização de cena. Nenhum modelo GLB, textura, personagem, som ou trecho de código desse projeto foi importado para o Navério.

## Fox.glb

O modelo rigado da raposa foi incorporado a partir de [Fox.glb](https://asset-explorer.needle.tools/downloads/Fox.glb), o ativo Fox da coleção oficial de exemplos glTF. O modelo é creditado a PixelMannen sob CC0; o rig e as animações são creditados a tomkranis sob CC BY 4.0; a conversão para glTF é creditada a AsoboStudio e scurest sob CC BY 4.0. O ativo é utilizado com as animações `Survey`, `Walk` e `Run`, e estes créditos devem permanecer junto ao projeto.

O bairro, a casa, os objetos urbanos, a criatura e o sistema de navegação do Navério foram desenhados e implementados para esta experiência. O projeto não reutiliza a narrativa, os sons ou o personagem de **Black Mirror**; a inspiração se limita à ideia geral de uma criatura digital com vida própria.

Ativos de terceiros incorporados no futuro também deverão ter suas licenças específicas verificadas e os créditos mantidos neste arquivo.
