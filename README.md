# Navério IA

Mundo 3D interativo de um único companheiro digital, construído com React, Vite e Three.js, preparado para a Vercel.

## Inspiração e referências

Estética e estrutura de cena inspiradas no projeto de mundo aberto [thaslle/world](https://github.com/thaslle/world) (MIT), com uma proposta nova: um único personagem que vive no ambiente e interage com o visitante. Não é um jogo de exploração.

## Rodar

```bash
npm install
npm run dev
```

## Publicar

Importe `fishixz/NaverioIA` na Vercel. Framework Vite, build `npm run build`, saída `dist`.

## Estado

Primeira versão visual; a integração com IA/voz ainda não foi implementada.
